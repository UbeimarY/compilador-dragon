# Compilador Dragon

Proyecto final de la asignatura **Compiladores** — Ingeniería de Software, Universidad Cooperativa de Colombia.

Compilador completo para el lenguaje **Dragon** (`.drg`), escrito en Python 3.10+ sin librerías externas.

Pipeline: `Tokens → AST → Análisis semántico → TAC → TAC optimizado → Ensamblador`
